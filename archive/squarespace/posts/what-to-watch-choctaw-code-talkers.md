# What to Watch: Choctaw Code Talkers

Jun 2

Written By [Guest User](/news-notes?author=6839f4dcc52c4707a9ee7c66)

As part of Vision Maker Media's "40 years, 40 films, 40 weeks" program, one archived PBS film will be re-released each week.

Watch them while they are available!

This week's featured film is: [Choctaw Code Talkers](http://americanarchive.org/catalog/cpb-aacip_508-x639z91993)

[![](images/8604f8cb-image-asset.jpeg)](http://americanarchive.org/catalog/cpb-aacip_508-x639z91993)

In 1918, not yet citizens if the U.S., Choctaw members of the US American Expeditionary Forces were asked to use their Native language as a powerful tool against the German Forces in WWI, setting a precedent for code talking.
